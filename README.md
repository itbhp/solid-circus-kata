# SOLID Refactoring Circus

![Carpa de circo](circus.png)

¡Bienvenidas y bienvenidos al SOLID Refactoring Circus! 🎪

En este coding dojo circense vamos a adentrarnos en la carpa de un circo (¡sin animales!) para ayudar a su equipo de desarrollo de software. Están creando una aplicación para gestionar las funciones del circo y quieren aplicar los principios **SOLID** desde el principio.

## ¿Cómo está organizado este repo?

Este coding dojo está preparado para dos lenguajes de programación: TypeScript y Java. En la raíz del repo encontrarás dos carpetas: `typescript` y `java`.

Dentro de la carpeta de cada lenguaje encontrarás las dos katas que vamos a resolver. Cada kata tiene su propia carpeta con un `README.md` que explica el problema a resolver y el código inicial.

Recuerda que cada kata es independiente y antes de empezar cada una tendrás que instalar las dependencias necesarias.

## Desafío

En este dojo te vamos a proponer que por unas horas no te ayudes de IA generativa para resolver las katas. Así mantendremos nuestra mente en forma 🧠💪.

## ¡A refactorizar!

Únete a alguna/ún compi de dojo y empezad a refactorizar. Recordad hacedlo siempre con una red de seguridad: los tests 🧪
